# NN - Lighting Sync

VRChat向けのlilToonライティング同期ツールです。

衣装に `NN - Lighting Sync` コンポーネントを追加すると、NDMFビルド時にアバター側のlilToon設定から以下を衣装側へ非破壊で同期します。

- 明るさの下限
- 明るさの上限
- モノクロ化

元のMaterial・Prefab・Sceneは変更しません。

## VCC / VPM

VPM Package ID:

`com.nekoneko.nn-lighting-sync`

`https://kureh4.github.io/NN-Lighting-Sync/index.json`

## Requirements

- Unity 2022.3
- VRChat Avatars SDK
- NDMF
- lilToon
